# Git Challenge: The Broken Website

Welcome to the challenge!

You've been given a repository containing multiple versions of a website. However, something has gone wrong along the way, and the current version is not working as expected.

Your task is to investigate the repository's history, identify a working version, and bring the website back to life.

## Your Mission

Complete the following tasks:

### 1. Explore the Repository
- Clone this repository to your local machine.
- Explore its folder structure and understand how the project is organised.
- Take a look at the available versions.

### 2. Investigate Git History
- Explore the commit history.
- Examine the changes made across different versions.
- Identify which version contains the correctly working website.

### 3. Restore the Website
- Restore the project to the working version you identified.
- Make sure the website runs correctly.

### 4. Add a New Feature
Once you've restored the website, it's time to make it better!
Implement a simple search bar that allows users to search through the tasks on the task board.

### 5. Work with Branches
- Create a new branch called `fixed-website`.
- Make your changes on this branch.
- Commit your changes with meaningful commit messages.
- Push your branch to your GitHub repository.

### 6. Create a Pull Request
- Create a Pull Request to merge your changes into the main branch.
- Include a brief description of what you fixed and the feature you added.

## Final Checklist

Before submitting, make sure you have:

- [ ] Identified the working version.
- [ ] Successfully restored the website.
- [ ] Implemented the search bar.
- [ ] Created a branch named `fix-website`.
- [ ] Committed and pushed your changes.
- [ ] Created a Pull Request.

**Good luck! Your mission is to bring the website back to life!!**
